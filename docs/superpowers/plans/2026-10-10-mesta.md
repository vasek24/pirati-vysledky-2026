# mesta.dg12.cz — Implementation Plan

> **For agentic workers:** use superpowers:subagent-driven-development. Each task T1–T7 is implemented by a **Sonnet** subagent in its own git worktree, branched from `mesta/main` (which the controller creates from `main`); every task diff gets an **Opus** review before merge into `mesta/main`. **Codex** reviews only the specifics (T9). The controller runs T8, T9 and all deploys. Steps use `- [ ]`.

**Spec:** `docs/superpowers/specs/2026-10-10-mesta-design.md` ("§" below). Read §1–§6 first.
**Goal:** staged on workers.dev by ~16:00, verified against ČSÚ after ~15:00, `mesta.dg12.cz` attached after the owner's review — without changing a byte of the Prague product.

## Global constraints (every task)
- Plain JS ESM, React 19, Vite 7, Vitest `~3.2`, Wrangler 4; UI copy in Czech; `npm test` = `TZ=UTC vitest run` (tests live under `src/**`, `api/**`, `cloudflare/*.test.js` — vitest does not see `scripts/`).
- **Forbidden edits** (§3.1): anything under `src/` except `src/mesta/**`; `api/**`; `cloudflare/*.js` except new `cloudflare/mesta-worker.js`, `cloudflare/mestaWiring.js`, `cloudflare/mestaWiring.test.js`; `cloudflare/wrangler.jsonc`; `index.html`; `vite.config.js`; `vercel.json`; `public/**`. Allowed shared edits are listed per task.
- ČSÚ time is zone-less Prague time: always `parseCsuTime` (`src/volby/format.js`).
- No browser code may reference `volby.gov.cz` data paths (`appdata/kv2026`).
- No deploys, no `git push` from implementers. Network only in T1 (ČSÚ files, gently, ≥ 1 s apart for per-town JSON) and T3 (data build, existing delays).
- Commits: imperative, one logical change, end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Before handing back: `npm test`, `npm run lint`, `npm run build` (Prague) green; tasks touching mesta front end also `npm run build:mesta` once T5 is merged.

**Interfaces produced (`src/mesta/registryCore.js`, pure, no I/O):**
- `normName(s) -> string` (NFC, `–`/`—`→`-`, no spaces around `-`, trimmed).
- `parseOwnerList(text) -> [{ region, name }]` (format of `docs/analysis/mesta-towns.txt`: `#` comments, `Region: A · B · C`).
- `wholeCouncils(kvrzcocoRows) -> Map<zastup:number, { zastup, name, kraj, okres, druh, population, precincts, rows:number }>` — `TYPZASTUP==='1' && DRUHZASTUP!=='4'`, deduped by KODZASTUP; `precincts` = Σ rows Σ(MAX−MIN+1) over `MINOKRSEK1..9/MAXOKRSEK1..9, MINOKRSE10/MAXOKRSE10`.
- `matchOwnerTowns(owner, councils) -> { matched:[{ name, region, zastup, flags }], unmatched:[name], ambiguous:[{ name, zastups }] }` — exact `normName` match; several → keep `druh ∈ {2,3}`; still ≠ 1 → ambiguous; flags `dash-normalized`, `disambiguated-by-druh`.
- `classifyTown(zastup, { lists, candidates, cvs, cns }) -> { type, list, members, others, flags }` per spec §6 (lists = kvros rows of that KODZASTUP; candidates = kvrk rows; join on `(KODZASTUP, COBVODU, POR_STR_HL)`; blank PSTRANA/NSTRANA tolerated).
- `borderlineReasons(town, { ownerZastups:Set, okresNames:Map<okres,name>, senateNames:Set, pirates2022:Map<zastup,{pct,seats}>, manual }) -> string[]` — `owner-list`, `okres-seat`, `senate-seat-2026`, `pirates-2022: 11,7 %, 2 mand.` (≥ 10 % or ≥ 1 seat), manual text.
- `decideInclusion(town, { type, reasons, override }) -> { inclusion:'auto'|'borderline-included'|'borderline-excluded'|'forced'|'excluded', reason }` per §4.1; `override.include === false` → `excluded` (reason from override); `include === true` → `forced`.
- `assignShards(published) -> published with shard` (group by kraj; `k = ceil(n/8)`; near-equal chunks of towns sorted by `localeCompare(…, 'cs')`; id `${kraj/100}-${i+1}`) and `assignFeatured(published, 12) -> featured 'top-1' (6 largest) / 'top-2' (next 6)`.
- `confidenceOf(flags, override) -> 'high'|'low'` (low-confidence flags: spec §6 rule 5).
- `renderSpecificsTable(rows, meta) -> markdown`, `renderVerification({ confirmed, rejected, added, borderlineExcluded, notes }, meta) -> markdown`.
`src/mesta/xlsxRows.js`: `xlsxRows(buffer) -> string[][]` (adm-zip; `xl/sharedStrings.xml` + `xl/worksheets/sheet1.xml`; cells by column letter; no new dependency).
